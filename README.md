# Mi Neto Shop - E-Commerce Frontend 🛒

Este es el frontend de una tienda online enfocada en tecnología, diseñada con una arquitectura "mobile-first" estilo retail. 

## 🚀 Demo en Vivo
[Visitar Mi Neto Shop](https://mineto-shop.vercel.app/)

## 🛠️ Tecnologías Utilizadas
* **Framework:** Next.js (App Router)
* **Estilos:** Tailwind CSS
* **Íconos:** Lucide React
* **Lenguaje:** TypeScript
* **Despliegue:** Vercel

## 📱 Características
* Diseño 100% responsivo adaptado para compras desde el celular.
* Interfaz limpia y moderna basada en paleta de colores corporativa (Azul marino y Naranja).
* Catálogo dinámico preparado para rotación de inventario.
